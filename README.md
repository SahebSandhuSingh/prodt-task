# Supplier Integration Layer (Step 1)

Clean, isolated Python module implementing the Supplier Integration Layer for a travel booking prototype.

## Quickstart

```bash
# 1. Create and activate virtual environment
python3 -m venv .venv
source .venv/bin/activate

# 2. Install dependencies
pip install -e .

# 3. Run unit tests
pytest -v tests/
```
